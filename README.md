# sudukooffline

A premium, offline-capable Sudoku Progressive Web App (PWA) built with React, TypeScript, Vite, and Tailwind CSS.

## Features
- Fully offline capable (PWA)
- Custom Sudoku engine (generation, solving, validation)
- Built-in hints and statistics tracking
- Themes: Light, Dark, AMOLED
- Haptic feedback and animations

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
